Jet Engines and Optimal Stopping

Replace too early and you waste useful life. Replace too late and you risk catastrophe.
Understanding Uncertainty · in-class group work

NASA's C-MAPSS turbofan degradation simulation gives 100 simulated jet engines, each run to failure. This activity builds up the full optimal-stopping toolkit on that real failure-time data: first the survival function and hazard rate (today's topic), then a fixed-age replacement baseline, a myopic one-cycle-ahead decision rule, and finally a full dynamic-programming stopping policy — the same backward-induction idea from the Dynamic Programming unit later in the course, previewed here on a concrete maintenance problem.

2 · Survival and hazard

The empirical survival function answers "what fraction of engines are still alive after age \(t\)?" The empirical hazard answers a sharper question: "among engines alive at age \(t\), what fraction fail at exactly age \(t\)?" With only 100 engines, the raw hazard is jagged — a 15-cycle rolling average smooths it for decision-making:

Notice the hazard is not monotonically increasing — it peaks around age 200, dips near 250, then rises again near 300. With only 100 engines, that dip may be real (a genuine "bathtub" pattern) or just sampling noise. Keep this in mind for Q5 — the dynamic program takes this exact hazard estimate at face value.

3 · Fixed-age replacement

The simplest policy: replace every engine at a fixed age \(K\), no matter what. If the true failure age \(T \ge K\), the cost is maintenance plus wasted remaining life; if \(T \lt K\), catastrophe:

$$\text{cost}(K, T) = \begin{cases} \$50 + \$1\cdot(T-K), & K \lt T \\ \$500, & K \ge T \end{cases}$$

Grid-searching \(K\) directly against all 100 engines' true failure ages finds the best fixed age:

\(K=134\) — well below the mean failure age of 206 — is the best fixed age, because $500 catastrophes are so much more expensive than wasted life that the policy would rather retire most engines quite early.

4 · Myopic stopping

A myopic operator only looks one cycle ahead: keep operating as long as the value of one more cycle (\(\$4\), say) exceeds the expected cost of a catastrophe in that one cycle, \(\text{hazard}(t)\times\$500\). Stop as soon as that inequality flips:

$$\text{stop when } \; \text{hazard}(t)\times\$500 \ge \$4$$

With the smoothed hazard from Q2, this rule first triggers at age 151 — evaluated against all 100 engines' true failures, that policy costs $137.57 on average, with a 7% catastrophe rate.

5 · Dynamic stopping on an age grid

A dynamic policy adds exactly one idea the myopic rule misses: continuing preserves the option to stop later. Working backward from the oldest observed age, compare stopping now against continuing — where continuing means paying the operating value, risking catastrophe this cycle, and otherwise facing tomorrow's already-computed value function:

$$V(t) = \min\Bigl(\underbrace{\$50}_{\text{stop}},\ \underbrace{-\$4 + \text{hazard}(t)\cdot\$500 + (1-\text{hazard}(t))\cdot V(t+1)}_{\text{continue}}\Bigr)$$

Solved on this data, the dynamic policy's first stop age is 181 — evaluated against the true failures, mean cost $216.69, a 30% catastrophe rate.

FAQ

Why smooth the hazard with a rolling window instead of using the raw estimate?

With only 100 engines, the raw hazard at any single age is estimated from a handful of failures (sometimes zero), so it swings wildly from one age to the next. A 15-cycle rolling average trades some resolution for a much less noisy input to the decision rules — at the cost of exactly the kind of non-monotonicity discussed in Q5.

Why does the myopic rule stop earlier than the dynamic rule here?

The myopic rule only weighs this cycle's catastrophe risk against this cycle's operating value — it never accounts for the option value of continuing to a potentially safer age. In a well-behaved (monotonically increasing) hazard, the dynamic rule would rationally stop later than the myopic rule for exactly that reason; here it does, but for the more complicated reason discussed above.
